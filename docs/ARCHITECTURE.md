# معمارية SMART Camel AI | SMART Camel AI Architecture

## العربية

هذا النموذج العام يستخدم معمارية عرض خفيفة بلا اعتماديات خارجية حتى يمكن تشغيله ومراجعته بسهولة. الهدف هو فصل إثبات القدرة الوظيفية عن الأسرار التنفيذية للمنصة الكاملة.

### الطبقات

1. طبقة الهوية والسجل
   - هوية رقمية لكل جمل.
   - بيانات السلالة والعمر والمزرعة والحالة.
   - سجل الملكية والشهادات والتتبع.

2. طبقة التشغيل
   - المزارع والقطعان.
   - الصحة والتغذية والنشاط.
   - السباقات والمزايين والمهرجانات والمزادات.

3. طبقة الاستشعار والمخاطر
   - بيانات مستشعرات اصطناعية.
   - السياج الجغرافي والرعي والمخاطر البيئية.
   - محرك مخاطر صحي تفسيري تجريبي.

4. طبقة الذكاء والتحليل
   - التوصيات والتنبؤ والتحليل.
   - تقييمات تجريبية للمزايين والسوق والجودة.
   - جميع المخرجات في الإصدار العام موسومة بوضوح عندما تكون محاكاة.

5. طبقة الأدلة والتدقيق
   - سجل ميزات مركزي.
   - حالة واضحة لكل قدرة.
   - سجل أحداث للمحاكاة والتفاعلات المهمة.

6. طبقة التكامل
   - نقاط تكامل مع البيئة والجهات الحكومية موضحة كـ Mock Integration فقط.
   - لا يدّعي هذا الإصدار وجود اتصال حي بجهة حكومية أو نظام إنتاجي.

### تصنيف النضج

- Implemented: وظيفة منفذة مباشرة داخل النموذج العام.
- Demonstrated: مسار وظيفي ظاهر ويمكن استعراضه ولكن ليس نظام إنتاج كامل.
- Simulated: نتيجة أو محرك يستخدم بيانات أو منطق محاكاة لإثبات السلوك.
- Mock Integration: نقطة تكامل معروضة مع عدم وجود اتصال خارجي حي.
- Planned: ضمن النطاق المعماري ولم تدخل بعد في الإصدار التشغيلي العام.

## English

The public MVP uses a lightweight dependency-free architecture so that it can be opened, reviewed and demonstrated easily. Its purpose is to separate functional capability evidence from protected implementation details of the full platform.

### Layers

1. Identity and registry layer
   - Digital identity for every camel.
   - Breed, age, farm and status records.
   - Ownership, certificates and traceability.

2. Operations layer
   - Farms and herds.
   - Health, feeding and activity.
   - Racing, beauty competitions, festivals and auctions.

3. Sensing and risk layer
   - Synthetic sensor data.
   - Geofencing, grazing and environmental risk.
   - Explainable demonstration health-risk engine.

4. Intelligence and analytics layer
   - Recommendations, prediction and analytics.
   - Demonstration beauty, market and product-quality assessment.
   - Public outputs are explicitly labelled when simulated.

5. Evidence and audit layer
   - Central feature registry.
   - Explicit maturity status for every capability.
   - Event trail for important simulations and interactions.

6. Integration layer
   - Environmental and government integration points are represented only as Mock Integration.
   - This release does not claim any live government or production-system connection.

### Maturity classification

- Implemented: directly implemented in the public demonstrator.
- Demonstrated: visible functional workflow but not a complete production subsystem.
- Simulated: output or engine uses synthetic data or simplified logic to demonstrate behaviour.
- Mock Integration: an integration point is represented without a live external connection.
- Planned: within the platform architecture but not yet activated in the public runtime.
