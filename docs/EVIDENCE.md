# مصفوفة الأدلة العامة | Public Evidence Matrix

## العربية

الغرض من هذه المصفوفة هو منع الخلط بين وجود الميزة في التصميم وبين إثبات تشغيلها في النموذج العام.

| فئة الإثبات | ما الذي يثبته الإصدار الحالي | حدود الإثبات |
|---|---|---|
| الهوية والسجل | عرض سجلات إبل اصطناعية ومعرفات مستقلة | لا يمثل سجلاً حكومياً حياً |
| الصحة | محرك مخاطر صحي تفاعلي ونتيجة تفسيرية | محاكاة وليست تشخيصاً بيطرياً |
| المستشعرات | مؤشرات نشاط وصحة واتصال تجريبية | لا توجد أجهزة فعلية متصلة بهذا الإصدار |
| المزادات | مسار مزايدة تجريبية وتسجيل الحدث | لا توجد معاملة مالية فعلية |
| الشهادات | تحقق تجريبي من CAMEL-001 | ليست شهادة حكومية أو قانونية |
| المزايين | درجة عرض تفسيرية | لا تمثل قرار تحكيم رسمي |
| المراعي والمخاطر | قدرات مدرجة ومحاكاة مخاطر | لا توجد بيانات أقمار صناعية حية في هذا الإصدار |
| الجينات والأنساب | تمثيل معماري وسجل قدرة | بيانات الحمض النووي الحقيقية غير منشورة |
| التكامل الحكومي | نقاط تكامل معلمة Mock Integration | لا يوجد ربط حكومي حي |
| البيئة الذكية | نقطة تكامل معلمة Mock Integration | لا يوجد اتصال حي بمنصة خارجية |
| التدقيق | سجل أحداث داخل جلسة العرض | ليس نظام سجل إنتاجي غير قابل للتغيير |

## قواعد الإفصاح

1. لا تُعرض بيانات حقيقية لأشخاص أو ملاك أو شركاء.
2. لا تُنشر الخوارزميات أو الأوزان أو قواعد القرار المملوكة.
3. لا تُقدّم المحاكاة على أنها تشغيل إنتاجي.
4. لا يُدّعى وجود تكامل خارجي حي بدون دليل تشغيل مستقل.
5. كل قدرة في سجل الميزات تحمل حالة نضج معلنة.

## English

This matrix prevents confusion between architectural scope and evidence of execution in the public MVP.

| Evidence category | What the current release demonstrates | Evidence boundary |
|---|---|---|
| Identity and registry | Synthetic camel records with independent identifiers | Not a live government registry |
| Health | Interactive health-risk engine with explainable output | Simulation, not veterinary diagnosis |
| Sensors | Demonstration activity, health and connectivity indicators | No physical devices are connected to this release |
| Auctions | Demonstration bid workflow and event logging | No real financial transaction |
| Certificates | Demonstration verification of CAMEL-001 | Not a government or legal certificate |
| Beauty competitions | Explainable demonstration score | Not an official judging decision |
| Grazing and risk | Registered capabilities and risk simulation | No live satellite feed in this release |
| Genetics and lineage | Architectural representation and capability registry | Real DNA records are not published |
| Government integration | Integration points labelled Mock Integration | No live government connection |
| Smart Environment | Integration point labelled Mock Integration | No live external-platform connection |
| Audit | In-session demonstration event trail | Not an immutable production ledger |

## Disclosure rules

1. No real personal, owner or partner data is published.
2. Proprietary algorithms, weights and decision rules are excluded.
3. Simulation is never presented as production deployment.
4. No live external integration is claimed without independently verifiable operational evidence.
5. Every capability in the feature registry carries an explicit maturity status.
