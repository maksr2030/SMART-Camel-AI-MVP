## قواعد الإفصاح

1. لا تُعرض بيانات حقيقية لأشخاص أو ملاك أو شركاء.
2. لا تُنشر الخوارزميات أو الأوزان أو قواعد القرار المملوكة.
3. لا تُقدّم المحاكاة على أنها تشغيل إنتاجي.
4. لا يُدّعى وجود تكامل خارجي حي بدون دليل تشغيل مستقل.
5. كل قدرة في سجل الميزات تحمل حالة نضج معلنة.
6. لا يُحتسب الترقيم التاريخي وحده كإثبات لوجود ميزة؛ المرجع هو الهوية الوظيفية والمحتوى المصدر.
7. ذكر قدرة في مادة براءة لا يُحوّلها تلقائياً إلى Implemented؛ حالة النضج تحدد بحسب دليل التشغيل العام المتاح.

## English

This matrix prevents confusion between architectural scope and evidence of execution in the public MVP.

| Evidence category | What the current release demonstrates | Evidence boundary |
|---|---|---|
| Capability registry | 231 canonical bilingual capability records after expanded source and patent-material reconciliation | Scope documentation does not prove 231 production-deployed capabilities |
| Source reconciliation | A documented method that rejects generic templates and accepts functionally identifiable source-backed capabilities | Original intellectual-property source files are not published in the public repository |
| Patent-backed capabilities | F224-F231 are traceable to a technical patent description and detailed operating documentation | This does not prove production cryptography, live integrations or an operating commercial system |
| Identity and registry | Synthetic camel records with independent identifiers | Not a live government registry |
| Health | Interactive health-risk engine with explainable output | Simulation, not veterinary diagnosis |
| Sensors | Demonstration activity, health and connectivity indicators | No physical devices are connected to this release |
| Auctions | Demonstration bid workflow and event logging | No real financial transaction |
| Certificates | Demonstration verification of CAMEL-001 | Not a government or legal certificate |
| Beauty competitions | Explainable demonstration score | Not an official judging decision |
| Grazing and risk | Registered capabilities and risk simulation | No live satellite feed in this release |
| Genetics and lineage | Architectural representation and capability registry | Real DNA records are not published |
| Optimized hybrid breeding | Patent-backed capability record | No real breeding outcome or production reproductive recommendation is provided in the public MVP |
| Security and encryption | Post-quantum encryption is documented as a Planned capability | The public repository contains no post-quantum implementation and makes no security-certification claim |
| Biosecurity | Documented capability scope | Not a live national epidemiological surveillance system |
| Training and extended reality | Source-backed capabilities classified as planned where no public runtime exists | No production virtual-reality environment is included in this release |
| Government and veterinary integration | Integration points labelled Mock Integration | No live government or veterinary-authority connection |
| Smart Environment | Integration point labelled Mock Integration | No live external-platform connection |
| Audit | In-session demonstration event trail | Not an immutable production ledger |

## Disclosure rules

1. No real personal, owner or partner data is published.
2. Proprietary algorithms, weights and decision rules are excluded.
3. Simulation is never presented as production deployment.
4. No live external integration is claimed without independently verifiable operational evidence.
5. Every capability in the feature registry carries an explicit maturity status.
6. Historical numbering alone is not accepted as evidence of a feature; functional identity and source content govern inclusion.
7. Appearance in patent-related material does not automatically make a capability Implemented; maturity is based on available public execution evidence.
