# Intellectual Property Notice | إشعار الملكية الفكرية وحدود الإفصاح

## العربية

### الغرض

تحدد هذه الوثيقة الحدود العامة للملكية الفكرية والإفصاح في مستودع SMART Camel AI العام. وهي وثيقة فنية/تنظيمية للمراجعة الأولية وليست بديلاً عن رأي قانوني أو اتفاق نقل ملكية أو ترخيص أو SPA نهائي.

### نطاق الأصول

تتضمن محفظة المنصة، بحسب السجل العام الحالي، ما يلي:

- 243 سجل قدرة معيارية F001-F243.
- 29 خوارزمية ومحركاً مسمىً وموثقاً في المصدر.
- نموذجَي تدريب مسميين في ملفات المصدر.
- 20 عائلة نظامية معيارية.
- وثائق معمارية ومطابقة مصدر وأدلة وعروض تشغيل.
- مواد تاريخية خاصة لا تُنشر في المستودع العام، تشمل تفاصيل خوارزمية ومنطقاً تنفيذياً وأمثلة برمجية ووثائق ملكية فكرية.

### ما هو منشور وما هو غير منشور

**منشور للعامة:**
- أسماء القدرات وحالات النضج.
- واجهة MVP والبيانات الاصطناعية.
- التوثيق العام، منهج المطابقة، الأدلة العامة والحدود المعروفة.
- أسماء الخوارزميات/المحركات عند الحاجة لإثبات نطاق المصدر، دون نشر التنفيذ الخاص.

**غير منشور ويجب حفظه في Data Room مقيدة:**
- ملفات المصدر التاريخية الخاصة الكاملة.
- الخوارزميات الأصلية وقواعد القرار والأوزان ومعاملات التقييم.
- بيانات التدريب أو البيانات البيطرية/الجينية/الشخصية الحقيقية.
- مواد البراءة أو الطلبات غير المعدة للإفصاح العام.
- العقود، اتفاقيات المساهمين/المطورين، تنازلات الحقوق وسجلات الإنشاء الخاصة.
- تفاصيل التقييم التجاري والتفاوض والاستحواذ.

### حدود الترخيص

هذا المستودع لا يحتوي حالياً على ملف LICENSE عام ضمن نطاق المراجعة الحالية. إتاحة المستودع للعامة لا ينبغي تفسيرها وحدها على أنها منح حق في إعادة الاستخدام التجاري أو إعادة الترخيص أو نقل الملكية الفكرية. أي حقوق استخدام أو نقل أو استحواذ يجب أن تحدد في وثيقة قانونية صريحة.

### متطلبات IP Due Diligence قبل الاستحواذ

يجب تجهيز ملف سري يتضمن على الأقل:

1. **IP Asset Register**: كل أصل، تاريخ الإنشاء، المؤلف/المساهم، النسخة، حالة السرية، والعلاقة بـF-ID أو Algorithm ID.
2. **Chain of Title**: مستندات تثبت انتقال أو احتفاظ حقوق الملكية لكل مساهم أو مطور أو جهة مشاركة.
3. **Patent/Registration Schedule**: أي طلبات أو تسجيلات أو أدلة إيداع أو أرقام مرجعية ذات صلة.
4. **Trade Secret Schedule**: قائمة الأسرار التجارية، من لديه حق الوصول، وكيف يتم حمايتها.
5. **Third-Party Components Register**: أي مكتبة أو خدمة أو نموذج أو بيانات لطرف ثالث ورخصتها وقيودها.
6. **Contributor Register**: من ساهم في الكود أو التصميم أو البيانات أو البحث، وما أساس حقوق الاستخدام.
7. **Domain/Brand/Trademark Register**: أسماء النطاقات والعلامات والأسماء التجارية عند وجودها.
8. **Source Evidence Map**: ربط الملفات الخاصة بالقدرات والخوارزميات دون رفع الملفات السرية إلى المستودع العام.
9. **Encumbrance Check**: التحقق من عدم وجود رهن أو ترخيص حصري أو التزام تعاقدي يقيّد نقل الأصل.
10. **Acquisition Transfer Schedule**: تحديد ما سينتقل في الصفقة: الكود، الوثائق، العلامة، البيانات، الأسرار التجارية، الطلبات، النطاقات، الحسابات والبيئات.

### قاعدة مهمة للمستحوذ

السجل العام يثبت **نطاقاً موثقاً ومنهجاً للفصل بين ما هو عام وما هو خاص**، لكنه لا يحل محل Chain of Title قانونية. الجاهزية النهائية للاستحواذ تتطلب أن تكون ملكية كل أصل قابل للنقل قابلة للإثبات داخل Data Room.

## English

### Purpose

This document defines the public intellectual-property and disclosure boundary for SMART Camel AI. It supports early technical diligence; it is not legal advice, an IP assignment, a license agreement or a final acquisition agreement.

### Portfolio scope

The current public record includes 243 canonical capabilities, 29 source-documented named algorithms/engines, two named training models, 20 canonical system families, and public architecture/evidence/reconciliation material. Private historical source, proprietary implementation logic, model parameters, confidential IP records and acquisition material remain outside the public repository.

### Licensing boundary

No public LICENSE file is currently present within the reviewed repository scope. Public accessibility alone should not be interpreted as a grant of commercial reuse, relicensing or ownership transfer. Any such rights must be set out in an explicit legal instrument.

### Required confidential acquisition evidence

The acquisition data room should contain an IP Asset Register, Chain of Title, patent/registration schedule, trade-secret schedule, third-party component/license register, contributor register, brand/domain schedule, source-evidence map, encumbrance review and a detailed transfer schedule defining exactly which assets move with the transaction.
