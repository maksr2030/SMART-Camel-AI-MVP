# النظرة العامة العامة | Public Platform Overview

## العربية

SMART Camel AI ليست تطبيقاً منفرداً لإدارة مزرعة أو سوق إبل. التصميم المستهدف هو طبقة تشغيل وذكاء متكاملة تربط هوية الجمل، حالته الصحية، نشاطه، نسبه، سلالته، المزرعة التي ينتمي إليها، بيئته، مشاركاته، معاملاته وشهاداته ضمن نموذج بيانات وتشغيل موحد.

بعد مطابقة محفظة المصدر التاريخية ومواد البراءة والملفات البيطرية والتشغيلية والخوارزمية، ثم إضافة مطابقة Phase 4 للقدرتين البيئيتين/الوراثيتين المستقلتين، يحتوي السجل العام الحالي على **245 سجل قدرة معيارياً F001-F245** باللغتين العربية والإنجليزية، مع **29 خوارزمية ومحركاً مسمىً موثقاً في المصدر** و**20 عائلة نظامية معيارية**. كان سجل Phase 1 التاريخي يقف عند F243؛ أما النطاق الحالي المعتمد في runtime والاختبارات فهو F001-F245.

الإصدار العام يركز على خمسة أمور:

1. اتساع النطاق الوظيفي الحقيقي للمنصة.
2. ربط المجالات المختلفة في تجربة تشغيل واحدة.
3. الفصل الصريح بين Implemented وDemonstrated وSimulated وMock Integration وPlanned.
4. تطبيق منهج مصدر يمنع احتساب القوالب العامة أو الأرقام التاريخية غير الموثقة كميزات فعلية.
5. فصل القدرات عن الخوارزميات وعن العائلات النظامية حتى لا يتم تضخيم الأرقام أو خلط طبقات المعمارية.

- إدارة المزارع والقطعان والمزارع متعددة الأغراض والمزارع العضوية.
- الصحة والسجل الطبي والتنبؤ بالأمراض والاستشارات البيطرية والتذكيرات الصحية.
- المراقبة الصحية الحرارية، النوم والرفاه، الإجهاد الحراري، وتحليل المخاطر الوراثية.
- الخصوبة والهرمونات وجداول التلقيح والتهجين ومراقبة الحمل والولادة.
- التغذية الذكية والتخطيط الغذائي وتحسين العليقة والتحكم التكيفي المغلق في التغذية.
- المستشعرات وإنترنت الأشياء والكاميرات الذكية والسياج الجغرافي.
- البصمة الصوتية وتحليل السلوك والتفاعل الاجتماعي ومؤشرات الرفاه.

- المخاطر البيئية وسلامة الطرق والإبعاد الصوتي والضوئي والحماية من المفترسات.
- الأمن البيولوجي وتقييم مخاطر الأمراض العابرة للحدود.
- الجينات والأنساب والتحليل الجينومي وتحسين السلالات والمحاكاة الوراثية.

- **F245: تقييم الأثر البيئي الإيجابي لتربية الإبل** بوصفه قدرة تقييم مستقلة لخصوبة التربة والغطاء النباتي والاستدامة وتقليل التصحر والتنوع الحيوي.
- السباقات والتحمل والمزايين ومسابقات الحليب وتحليل الأداء والتقييم والنتائج.
- تتبع GPS والسرعة أثناء السباقات في الزمن الحقيقي كقدرة موثقة ومخطط لها.
- تقييم الجمال حسب السلالة والجنس والحركة والمعايير المحلية والدولية.
- كشف التلاعب باستخدام الأشعة تحت الحمراء والموجات فوق الصوتية والتصوير الطيفي والمقطعي ضمن حالات النضج المعلنة.
- إدارة المهرجانات والجدولة والفعاليات المتزامنة ومطابقة المهرجان والواقع المعزز والافتراضي والتحليل المباشر.
- التفاعل الجماهيري والتصويت والتقييم والمكافآت والشارات والإعلانات والتحليلات الإعلامية.
- المزادات والتأهيل والمتابعة والتقييم السوقي والتقييم الصحي والجيني قبل التجارة.
- السوق والتفاوض والاستيراد والتصدير وتتبع الشحنات والخدمات اللوجستية.
- الملكية والشهادات والتحقق والتتبع وسلسلة التوريد.
- الحليب واللحوم وجودة المنتجات واختبار المنتجات والشهادات وتتبع الإنتاجية عبر دورة الحياة.
- التحليلات والرسوم الديناميكية والمقارنات والتنبؤ والتوصيات والاقتصاد التشغيلي.
- التدريب الافتراضي والتعلم التفاعلي والشهادات التدريبية.
- شبكة التواصل المهني ومركز البيانات العالمي وقياس رضا المستخدم.
- الاستدامة وإدارة الموارد والتوصيات الخاصة بالطاقة المتجددة في المزارع.
- التوسع العالمي والأمن والامتثال وتشفير ما بعد الكم كقدرة Planned.
- التكاملات المؤسسية والبيئية والبيطرية الممثلة كنقاط Mock Integration فقط.
- التراث والتعليم والسياحة المرتبطة بقطاع الإبل.

### تنظيم العائلات النظامية

تم تنظيم **245 قدرة** في 20 عائلة نظامية معيارية تشمل الهوية، الصحة، السلوك، الجينات، التكاثر، التغذية، المزارع، البيئة، السلامة الميدانية، IoT، المزايين، السباقات، المهرجانات، المزادات، التجارة، الإنتاج، الجمهور، التحليلات، الحوكمة والأمن، ثم التكامل والبحث والتدريب والمجتمع والتراث.

هذه العائلات لا تعني 20 تطبيقاً منفصلاً؛ هي طبقة معمارية لتوضيح ترابط المنصة.

### سجل الخوارزميات والمحركات

تتضمن محفظة المصدر 29 اسماً لخوارزميات ومحركات موثقة بعد إزالة التكرار، إضافة إلى نموذجَي تدريب مسميين. يعرض المستودع الأسماء والعلاقة الوظيفية فقط، ولا ينشر الأكواد أو الأوزان أو مجموعات التدريب أو منطق القرار الخاص.

### لماذا النموذج العام بلا اعتماديات تشغيل خارجية

تم اختيار واجهة HTML وCSS وJavaScript خفيفة حتى يستطيع المراجع فتح النموذج محلياً أو نشره كصفحة ثابتة دون مفاتيح سرية أو قواعد بيانات أو خدمات مدفوعة. هذا يقلل مخاطر الإفصاح ويجعل المراجعة التقنية الأولية مباشرة.

## English

SMART Camel AI is not a single farm-management or camel-market application. Its target architecture is an integrated operating and intelligence layer connecting camel identity, health, activity, lineage, breed, farm context, environment, participation history, transactions and certificates within one coherent model.

After reconciliation of the historical source portfolio, patent-related material, veterinary, operating and algorithm-focused files, plus the Phase 4 reconciliation of two independent environmental/genetic capabilities, the current public registry contains **245 canonical capability records, F001-F245**, together with **29 source-documented named algorithms and engines** and **20 canonical system families**. The historical Phase 1 baseline ended at F243; the current runtime and validation scope is F001-F245.

The public release demonstrates scope breadth, cross-domain integration, explicit maturity boundaries, source-governed counting, and separation of capabilities from algorithms and system families.

Two Phase 4 additions are explicitly retained as Planned source-backed capabilities:

- **F244 — Genetic Breeding with Environmental Impact Analysis.**
- **F245 — Positive Environmental Impact Evaluation for Camel Breeding.**

The **245 capabilities** are organized into 20 architectural system families rather than twenty separate applications. The source portfolio also contains 29 normalized named algorithms/engines plus two named training models; the public repository exposes names and functional relationships only, not proprietary code, weights, datasets or confidential decision logic.

A lightweight HTML/CSS/JavaScript runtime is intentionally used so reviewers can run the demonstrator without secret keys, databases or paid runtime services while preserving the public/private IP boundary.
