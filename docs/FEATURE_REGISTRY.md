# Acquisition Feature Registry | سجل القدرات للاستحواذ

## العربية

### الغرض

هذا السجل هو مرجع العناية الواجبة لكل قدرة معيارية في SMART Camel AI. لا يستخدم الترقيم التاريخي كدليل مستقل؛ المرجع هو F-ID المعياري، حالة النضج الحالية، وفئة الدليل.

### تصنيف دليل العناية الواجبة

- **PE — Public Executable:** قدرة منفذة مباشرة في الـMVP العام.
- **PD — Public Demonstrable:** مسار وظيفي ظاهر وقابل للاستعراض.
- **PS — Public Simulation:** منطق أو نتيجة محاكاة قابلة للاستعراض.
- **MI — Mock Integration:** نقطة تكامل فقط دون اتصال خارجي حي.
- **SD — Source Documented:** قدرة موثقة في المصدر لكنها Planned في الإصدار العام.

### فئات المصدر

- **Baseline:** السجل الأساسي العام ومصادر المنصة المطابقة.
- **Legacy Detailed:** وثائق مصدر تفصيلية جرى توحيدها.
- **Patent:** قدرة موثقة ضمن مواد براءة/وصف تقني مرتبط.
- **Final Operating:** ملفات بيطرية/تشغيلية نهائية.
- **Final Algorithmic:** ملفات تفصيلية أخيرة ذات هوية خوارزمية أو نظامية مستقلة.

> قاعدة مهمة: PE/PD/PS/MI/SD هي **نوع الدليل العام الحالي** وليست حكماً على القيمة التجارية أو الملكية الفكرية.
